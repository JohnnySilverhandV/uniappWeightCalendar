# 体重日历 · Weight Calendar

一个**纯本地**的每日体重记录应用。打开就是一个月历，点哪一天就录哪一天，一眼看完这个月的体重起伏。

不联网、不登录、无广告、无充值套路——没有账号体系，也没有服务器，数据只存在你自己的设备上。

基于 uni-app（Vue 3）开发，可打包成 Android APK；另附一份**零依赖单文件网页版**，手机浏览器直接打开就能用。

---

## 功能

| 功能 | 说明 |
|---|---|
| 月历记录 | 一屏总览整月，有记录的日期显示体重与对勾角标 |
| 数字键盘录入 | 点击日期唤起小键盘，逐位输入，带退格与确认 |
| 斤 / 公斤自动识别 | 按数值区间智能判断单位，换算结果会明确提示，也可手动切换 |
| 环比趋势 | 每天显示相对上一次记录的增减（增重 / 减重多少斤） |
| 月份切换 | 左右切换月份，带方向滑动过渡 |
| CSV 导出 / 导入 | 导出全量记录备份，换机或重装后导入恢复 |
| 完全离线 | 不发起任何网络请求 |

## 界面与动效

- **毛玻璃质感**：头部、日历卡片、详情卡、数字键盘均为半透明虚化（`backdrop-filter`），背景三色光斑缓慢漂移
- **保存成功动效**：全屏圆环从 0 逐渐填满 → 对勾按笔画顺序逐笔画出 → 「已记录」浮现，整体 1.6 秒
- **体重数字滚动**：保存后数字从旧值平滑滚动到新值
- **按压反馈**：日期格子与按钮按下有缩放回弹手感

## 使用

### 方式一：网页版（零安装）

下载 [`offline-app/index.html`](offline-app/index.html)，用手机或电脑的浏览器打开即可。

单个 HTML 文件，没有任何外部依赖（无 CDN、无字体、无脚本引用），断网也能正常使用。

### 方式二：Android 安装包

到 [Releases](https://github.com/JohnnySilverhandV/uniappWeightCalendar/releases) 页面下载最新 APK，直接安装。

> 安装时系统可能提示「未知来源应用」，需在设置中允许本次安装。这是所有非应用商店分发的 APK 的通用行为。

## 数据说明

**这一点很重要，请看完再用。**

- 存储位置：设备本地（App 用 `uni.setStorageSync`，网页版用 `localStorage`），键名都是 `weight_records_v2`
- 数据结构：`{ "2026-10-28": { "weight": 123.4 } }`，日期为 `YYYY-MM-DD`，体重单位为斤
- **没有云端同步，也没有服务端备份**——清除应用数据、清除浏览器缓存、卸载重装，记录都会消失
- 数据格式两版互通：网页版导出的 CSV 可以导入 App，反之亦然

**建议养成习惯**：换机、升级、卸载之前，先点一次「导出」把 CSV 存到相册/文件里，重装后再「导入」恢复。

## 本地开发

需要 [HBuilderX](https://www.dcloud.io/hbuilderx.html)（uni-app 官方 IDE）。

```bash
git clone https://github.com/JohnnySilverhandV/uniappWeightCalendar.git
```

1. HBuilderX → 文件 → 导入 → 从本地目录导入，选中项目根目录
2. 运行 → 运行到浏览器（H5 调试）或 运行到手机或模拟器（真机调试）
3. 发行 → 原生 App 云打包，生成 APK

网页版无需构建，改完 `offline-app/index.html` 直接刷新浏览器即可。

### 测试模式

连续点击页面标题 **5 次**（2 秒内完成），可进入测试模式：

- 可以修改任意历史日期的记录（正式模式下只能改今天）
- 提供「填充模拟数据」「清空所有数据」两个工具
- 点标题旁出现的退出按钮可返回正式模式

## 实现要点

开发过程中踩到的几个坑，记录在此，避免后续维护重复试错。

### App 端不支持 `<svg>`

uni-app 打包成 APK 后，页面模板里的 `<svg>` 标签会在编译阶段被**直接丢弃**——浏览器 H5 里显示正常，装到手机上元素就消失了。

因此圆环和对勾都不能用 SVG 绘制：

- 圆环：`view` + `conic-gradient`，配合 20 个关键帧实现角度 0°→360° 的逐帧填充
- 对勾：**内嵌 base64 PNG 位图**（不是 CSS 拼笔画）

### 为什么对勾用位图

最初尝试用两根圆角 `view` 旋转拼接，在浏览器里还行，App 的 webview 里拐角处永远缺一个角；换成单元素 `border-bottom` + `border-right` 旋转，形状对了但笔画方头、呆板，观感很差。

最终改为用脚本光栅化生成图片：480×480 画布、4 倍超采样抗锯齿、圆头笔画、绿色轻微渐变。以 base64 直接写进 CSS，不引入外部文件依赖，两端渲染**完全一致**。

「从左往右逐渐画出」的效果由外层裁剪容器的宽度动画实现（0 → 168rpx），不依赖 SVG 的 `stroke-dashoffset`。

### `requestAnimationFrame` 不可靠

数字滚动动画原先用 `rAF` 驱动，App 端 webview 下表现不稳定，数值没能写入。改用 `setInterval` 后两端一致。
